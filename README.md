# ♻️ E-Waste Logistics & Routing Platform

A full-stack MERN application to coordinate consumer e-waste drop-offs and route inventory to recycling facilities.

## Tech Stack
- **Frontend:** React.js, Axios, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (with geospatial queries)
- **Auth:** JWT Authentication

## Features
- User registration and login with JWT
- Submit e-waste drop-off tickets
- Admin dashboard to track and manage tickets
- Real-time status updates (pending → processing → completed)
- Geospatial queries to find nearby recycling facilities
- Role-based access (user vs admin)
